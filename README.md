# SunProsto — лендінг сонячних станцій для бізнесу

Односторінковий сайт (landing page) компанії **SunProsto**, яка проєктує та встановлює
сонячні станції для бізнесу. Сторінка українською мовою і містить блоки: hero,
реалізовані проєкти, послуги, калькулятор/заявка на розрахунок, відгуки,
5 кроків до запуску, контактну секцію та плаваючий віджет зв'язку
(телефон, Telegram, Viber, email, Instagram).

## Технології

- Статичний HTML/CSS/JS в одному файлі — `public/index.html`
- Без фреймворків, без збірки та без залежностей (`npm install` не потрібен)
- Зображення вбудовані в HTML як base64, тому зовнішніх ассетів немає
- Google Tag Manager для аналітики; кліки по контактах пишуться у `dataLayer`
  як подія `contact_click`
- Хостинг: Netlify (див. `netlify.toml`, публікується каталог `public`)

## Заявки в Telegram

Форми на сайті надсилають заявку на `/api/lead` — це Netlify-функція
`netlify/functions/lead.mts`, яка пересилає ім'я, телефон, назву форми, сторінку
та UTM-мітки у Telegram. Токен бота в HTML/JS не потрапляє: функція читає його
зі змінних оточення сайту.

Потрібно задати дві змінні (Netlify → Site configuration → Environment variables):

| Змінна | Значення |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `TELEGRAM_CHAT_ID` | ID чату або групи, куди слати заявки (кілька — через кому) |

Якщо змінні не задані, ендпоінт відповідає `503 not_configured`, а форми на сайті
працюють як раніше (валідація, підтвердження, подія `generate_lead`).

## Локальний запуск

```bash
netlify dev --port 8889
```

Далі відкрити http://localhost:8889.

Альтернативно достатньо будь-якого статичного сервера, наприклад:

```bash
npx serve public
```

## Деплой

Пуш у ветку — Netlify публікує вміст `public/` без кроку збірки.

## Структура

```
public/index.html          — весь сайт (розмітка, стилі, скрипти, зображення)
netlify/functions/lead.mts — приймає заявки з форм і шле їх у Telegram
netlify.toml               — налаштування публікації та HTTP-заголовки
AGENTS.md           — контекст проєкту для AI-агентів
```
